# CRUD Application

A responsive CRUD application built with React and Vite.  
This application allows users to manage data efficiently with Create, Read, Update, and Delete operations while providing authentication functionality.

## Features

- User Authentication
  - Sign Up
  - Sign In
  - Log Out

- CRUD Operations
  - Create new records
  - Display existing data
  - Update records
  - Delete records

- RESTful API integration
- Data fetching and API response handling
- Form handling and validation
- Reusable React components
- Responsive design for different screen sizes

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- REST APIs
- React Router
- HTML5
- CSS3
